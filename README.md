# nodejs-version-info

> **This repository is archived.** The tool now lives in
> [nvitaterna/nodejs-distroless](https://github.com/nvitaterna/nodejs-distroless)
> under `tools/version-info/`, where the hourly version check runs it
> directly. The `nvitaterna/nodejs-version-info` Docker Hub image is not
> updated anymore.

Lists the Node.js versions (maintenance, LTS and current release lines) that
[nodejs-distroless](https://github.com/nvitaterna/nodejs-distroless) builds
images for, read from nodejs.org's release schedule and download index.
